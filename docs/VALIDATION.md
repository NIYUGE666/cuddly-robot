## 模型结果

四路各自目标频率分量经校准为 6.3662 / 2.1221 / 1.2732 / 0.9095 Vpk、相位约 0°。计算保留 1–101 次奇次谐波通过各滤波器后的带外残留，没有把滤波器输出人为替换为纯正弦。

包含带外泄漏、求和运放带宽和 100 kΩ 负载后，合成输出中 1/3/5/7 次分量峰值约为 6.3617 / 2.1149 / 1.2603 / 0.9013 V，所选四项相对幅度比例最大误差约 0.95%，相位偏差绝对值小于 0.70°。合成总 Vpp 约 11.8377 V，理想四项傅里叶合成为 11.8423 Vpp。输出模型最大斜率约 0.159 V/µs，未加入非线性压摆或饱和模型。

这些数值依赖校准和所选线性模型，不是实物精度保证。TL082 的失调、噪声、输出摆幅/电流、实际 GBW 差异、器件容差和公共地阻抗仍需验证。
