# 嘉立创 EDA 专业版导入说明

本仓库交付的是**可编辑的交换工程**，不是已在嘉立创软件中保存过的原生 `.epro` 文件。当前环境没有嘉立创 EDA 专业版 GUI，不能宣称“已实际直接导入成功”。软件版本和启用的导入器可能不同，应使用专业版当前支持的对应格式。

## 导入文件

**请重新下载 Rev B，旧版解压文件不会自动更新。** `waveform_RevB_wired_KiCad9_import.zip` 和 `waveform_RevB_wired_EAGLE_XML_import.zip` 是为避免浏览器缓存而提供的新版明确命名包，与下述普通文件名包内容相同。

* `release/waveform_KiCad9_import.zip`：Rev B 单页有线原理图、PCB、工程配置、独立符号库与封装库。由 KiCad **9.0.2** 生成，不冒称为旧版 KiCad 格式。
* `release/waveform_EAGLE_XML_import.zip`：`waveform.sch` 与 `waveform.brd`，使用 EAGLE 9.6 XML 交换格式，两份文件都内嵌符号、封装和引脚映射。另附 BOM。

在专业版的文件/工程导入功能中选择对应格式，导入完整 ZIP 或解压后的文件对（依软件导入器提示）。对于 KiCad，选择 `hardware/waveform.kicad_sch`；这是 Rev B 的单张 A0 有线原理图，不再包含旧版六张子页。PCB 为同目录 `waveform.kicad_pcb`。

如果当前专业版导入器不接受 KiCad 9，不要只改文件扩展名或格式版本号；应尝试其支持的 EAGLE XML 导入器，或由实际安装的兼容 EDA 工具执行正规转换。当前环境无法查询在线导入器版本，也没有验证专业版接受上述版本，因此“导入可用”仍是交付验收中的待验证项。

`release/waveform_Gerber_prototype.zip` 只是制板图形输出，**不能代替可编辑原理图/PCB 工程导入**。完成导入复核、实物打样计划及装配尺寸确认后再考虑制板。

## 导入后必须核对

1. 单张 A0 分区有线原理图，16 个 IC：U1=NE555P、U2=CD4013BE、U3–U16=14 片 TL082CP。TL082 已拆分为 A/B 放大单元和独立电源单元，三者共用同一器件编号，不能丢失 4/8 脚电源。
2. 板上 190 个封装（包括 18 个裸测试焊盘）、491 个物理引脚，489 个接网引脚和 2 个明确 NC 的 U2 备用输出。KiCad 会给 NC 引脚生成独立的 `unconnected-…` 内部网络；交换格式可将它们保持未连接。
3. 双层板，外形 229 × 231 mm；2522 段走线、151 个过孔。导入器可能合并同一直线上的线段，因此线段数量可变化，但网络连通性不能变化。特别检查底层没有翻错、板框闭合、过孔贯通。
4. J5-1/2/3 为 +12 V/GND/−12 V。U1 不允许跨接 24 V；U2 电源与时钟必须正确；C3 正极朝 Q1，负电源 47 µF 电解正极朝 GND。
5. 22 个 3296W 电位器的 1/2/3 脚与实物一致；滤波/移相使用的电位器 2、3 脚相连，调幅电位器则三脚独立。四个极性跳线默认 2–3，只放一个短路帽。
6. Rev B 使用单页局部网络标签命名电源和信号，通道内部用实际导线连接；接地符号旁有 GND 标签。KiCad 网表中的 `/` 是根路径前缀。对照 `circuit.json`、`validation/netlist.xml` 和 BOM 检查引脚网络，重新运行专业版 ERC/DRC；本地 KiCad 的零违规不能自动延续到转换后的工程。
7. 原始符号和封装没有绑定立创商品编号。需要贴片/采购服务时另行匹配真实物料并核对数据手册，不能仅凭名称自动下单。
8. 确认通过后，在专业版中保存为其原生可编辑工程，再导出 `.epro` 或软件提供的完整工程包，记录软件版本和导入后检查结果。项目包含完整 2D 符号/封装；没有随包附带 3D STEP 模型，缺少 3D 预览不代表 2D 网络连接丢失。

EAGLE PCB 已经通过 KiCad 的实际 EAGLE 导入器回读，元件、引脚网络、走线和过孔数量经过核对；EAGLE 原理图已检查 XML 结构及引脚引用与 PCB 一致。**这些检查不等价于嘉立创 EDA 专业版 GUI 导入验证。**
